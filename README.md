Engine9000 is a source-level debugger and profiler for Amiga, Neo Geo, and
Mega Drive development. It includes frame stepping, rewind, hardware viewers,
and replay checks for video and audio. File formats can change between releases.

## Get started

Build the debugger for your platform using the [build instructions](docs/engine9000-public-guide.md#building).
Launch the debugger and select a game or machine configuration. Neo Geo BIOS
and Amiga Kickstart ROMs must be supplied separately.

- [Runtime and ROM setup](docs/engine9000-public-guide.md#runtime-requirements)
- [Controls](docs/engine9000-public-guide.md#controls) and
  [debugger console](docs/engine9000-public-guide.md#console-commands)
- [Z80 debugger](e9k-debugger/readme-z80.md)
